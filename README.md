# Проект

**Автор:** Космицкая Дарья, гр. 450502
**Дисциплина:** Жизненный цикл разработки программного обеспечения

## Описание проекта

В данном репозитории будет выполняться проектирование и разработка задания по дисциплине «Жизненный цикл разработки программного обеспечения». Проект представляет собой утилиту для декодирования текста из Азбуки Морзе.

## Структура репозитория

- `lab1/` — материалы лабораторной работы №1 (утилита декодирования Морзе);
- `docs/` — документация;
- `srs/`, `sdd/`, `adr/` — шаблоны документации;
- `app/` — пустой проект для дальнейшей разработки.

## Стек технологий

- Java 17
- Swing
- IntelliJ IDEA
