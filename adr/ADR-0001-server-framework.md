# Серверный фреймворк — Spring Boot



## Контекст и постановка задачи

Серверная часть «Puff \& Plate» должна реализовывать REST API, аутентификацию, работу с PostgreSQL и бизнес-логику расчета стоимости (включая бесплатную доставку). Ограничение SRS требует Java. Нужно выбрать фреймворк, который обеспечит безопасность (REQ-SEC-001) и быструю разработку.



Вопрос: какой серверный фреймворк на Java выбрать, чтобы минимизировать написание рутинного кода?



## Драйверы решения

* Зрелая поддержка безопасности (BCrypt, защита от CSRF/XSS) — REQ-SEC-001.

* Готовые решения для работы с БД (JPA/Hibernate).

* Знакомство команды с инструментом.



## Рассмотренные варианты

* Spring Boot 3

* Quarkus

* Jakarta EE (WildFly)



## Итог решения

Выбранный вариант: \*\*«Spring Boot 3»\*\*, потому что он даёт готовые модули Spring Security, Spring Data JPA и подробную документацию. Quarkus быстрее стартует, но для учебного проекта это не критично. Jakarta EE требует настройки сервера приложений, что усложняет развёртывание в Docker.



### Последствия

* \*\*Хорошо:\*\* безопасность и работа с БД реализуются конфигурацией, а не с нуля.

* \*\*Плохо:\*\* Spring Boot потребляет больше памяти.



### Подтверждение

* Успешная компиляция проекта через Maven.



## Плюсы и минусы вариантов



### Spring Boot 3

* **Хорошо**, потому что закрывает требования безопасности «из коробки».

* **Плохо**, потому что требует больше памяти.



### Quarkus

* **Хорошо**, потому что быстрый старт.

* **Плохо**, потому что меньше примеров для junior-разработчиков.



## Дополнительная информация

Связанные требования: REQ-SEC-001, REQ-PERF-001.
