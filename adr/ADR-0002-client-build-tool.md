# Клиентская часть — React SPA на Vite



## Контекст и постановка задачи

Ограничение SRS фиксирует React для интерфейса. Нужно выбрать инструмент сборки, чтобы сборка была быстрой, а конфигурация минимальной.



## Драйверы решения

* Скорость сборки и запуска для разработки.

* Поддерживаемость инструмента.

* Минимальная конфигурация.



## Рассмотренные варианты

* Create React App

* Vite

* Next.js



## Итог решения

Выбранный вариант: **«Vite»**, потому что Create React App устарел, а Next.js добавляет серверную часть, которой в нашей архитектуре нет (сервер уже Spring Boot). Vite даёт быструю сборку и минимальную конфигурацию.



### Последствия

* **Хорошо:** сборка занимает секунды.

* **Плохо:** некоторые старые туториалы написаны для CRA.



### Подтверждение

* Сборка `npm run build` проходит без ошибок.



## Плюсы и минусы вариантов



### Vite

* **Хорошо**, потому что быстрый запуск.

* **Нейтрально**, потому что требует настройки маршрутизации для SPA.



### Create React App

* **Плохо**, потому что не поддерживается.



### Next.js

* **Плохо**, потому что добавляет лишний сервер.
