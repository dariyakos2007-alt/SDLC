\# Глоссарий проекта «Puff \& Plate»



В данном документе приведены определения ключевых доменных и технических терминов, используемых в проектной документации (SRS, SDD, ADR) для обеспечения однозначного понимания требований всеми участниками разработки.



| Термин | Определение |

| :--- | :--- |

| \*\*Кейтеринг\*\* | Организация выездного питания и обслуживания мероприятий. |

| \*\*Клиент\*\* | Единственная роль пользователя системы (согласно SRS). Лицо, оформляющее заказ на мероприятие. |

| \*\*Сет\*\* | Готовый набор блюд, рассчитанный на определённое количество человек. |

| \*\*Блюдо\*\* | Отдельная позиция каталога (название, цена, описание, ингредиенты). |

| \*\*Аллерген\*\* | Ингредиент, по которому клиент может исключить блюда из каталога (REQ-FUNC-006). |

| \*\*Корзина\*\* | Список выбранных клиентом сетов и блюд перед оформлением заказа. |

| \*\*Промокод\*\* | Уникальный код, дающий скидку на итоговую сумму заказа (REQ-FUNC-007). |

| \*\*Порог бесплатной доставки\*\* | Правило: если сумма заказа >= 200 BYN, доставка бесплатна, иначе — 15 BYN (ADR-0004). |

| \*\*Заказ\*\* | Сохранённая в БД заявка клиента с уникальным номером и статусом (REQ-FUNC-005). |

| \*\*История заказов\*\* | Список прошлых заказов клиента в личном кабинете (REQ-FUNC-008). |

| \*\*API\*\* | Application Programming Interface — программный интерфейс для взаимодействия Frontend и Backend. |

| \*\*SPA\*\* | Single Page Application — одностраничное веб-приложение (архитектура фронтенда на React). |

| \*\*JWT\*\* | JSON Web Token — токен аутентификации, передаваемый между клиентом и сервером (ADR-0003). |

| \*\*REST\*\* | Representational State Transfer — архитектурный стиль взаимодействия компонентов в сети. |

| \*\*SRS\*\* | Software Requirements Specification — спецификация требований к ПО. |

| \*\*SDD\*\* | Software Design Description — описание дизайна программного обеспечения. |

| \*\*ADR\*\* | Architecture Decision Record — протокол архитектурных решений. |

| \*\*MVP\*\* | Minimum Viable Product — минимально жизнеспособный продукт (версия с базовым функционалом). |
